
# MediScan - Alexa Health Companion

An AI-powered health companion that scans medical reports and provides voice assistance via Alexa.

## Features
- Medical report scanning with TensorFlow
- Voice interaction with Alexa Skills
- Health dashboard with React + Next.js
- Real-time charts with Chart.js
- AI insights with Gemini API

## Built With
python, react, next.js, tensorflow, gemini-api, chart.js, tailwindcss, node.js

## How to run
npm install
npm run dev
